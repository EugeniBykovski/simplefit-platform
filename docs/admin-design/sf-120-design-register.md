# SF-120 — Control Plane entry and first visit: design discrepancy register

Design source: Claude Design `AdminSignIn` (AD0, board 19.1), `FirstRunAdmin` (ARW1,
board 34.24) and `AdminNav` (mode `mvp`), canvas version `1794299393-d9d6`, read
with the Artifact tool. Backend: simplefit-api ADR 0028 (operators, WebAuthn,
step-up) and ADR 0018 (first-run experience `control_plane_web_tour`, SF-120).

Every deviation below keeps the product truthful: nothing is shown as available,
granted or recorded unless the backend says so, and nothing points at a page that
doesn't exist. None of them changes a token. D-SA25 ("presentation only, never a
gate") is still PROPOSED; this build follows it: ARW1 is offered once and never
blocks the Control Plane.

## Not in scope here

- A step-up-gated action in the web UI (the design's "Sensitive actions" flow): no
  admin action page exists yet. The fresh-key action contract is covered over HTTP
  by simplefit-api (SF-116).
- Production operator access: the production bootstrap ceremony is blocked
  (D-SA13, ADR 0028); this build runs end-to-end only with the development ceremony.
